# 💪 Bodyweight Tracker

A modern, responsive web application for tracking your bodyweight progress over time. Built with vanilla JavaScript and featuring a beautiful, intuitive interface.

## ✨ Features

### 📊 **Statistics Dashboard**
- Current weight display
- Total weight change tracking
- Average weight calculation
- Total entries counter

### 📝 **Weight Entry Management**
- Easy-to-use form for adding weight entries
- Date selection (defaults to today)
- Optional notes for each entry
- Edit and delete existing entries

### 📈 **Progress Visualization**
- Interactive line chart showing weight trends over time
- Powered by Chart.js for smooth, responsive charts
- Visual progress tracking with hover details

### 🧮 **BMI Calculator**
- Automatic BMI calculation based on height and current weight
- BMI category classification (Underweight, Normal, Overweight, Obese)
- Height saved automatically for future calculations

### 📱 **Mobile-Friendly Design**
- Fully responsive layout that works on all devices
- Touch-friendly interface
- Modern gradient design with smooth animations

### 💾 **Data Persistence**
- All data stored locally in your browser
- No server required - works offline
- Automatic saving of entries and user height

## 🚀 Getting Started

1. **Open the App**: Simply open `bodyweight-tracker.html` in any modern web browser
2. **Add Your First Entry**: 
   - Fill in today's date (pre-filled)
   - Enter your weight in kilograms
   - Add optional notes if desired
   - Click "Add Entry"
3. **Set Your Height**: Enter your height in the BMI calculator section for automatic BMI calculations
4. **Track Progress**: Continue adding entries to see your progress over time in the chart

## 🎯 How to Use

### Adding Weight Entries
1. The date field defaults to today's date
2. Enter your weight in kilograms (supports decimals like 70.5)
3. Add optional notes about how you're feeling, workout status, etc.
4. Click "Add Entry" to save

### Viewing Your Progress
- **Statistics Cards**: See your current weight, total change, average weight, and entry count at the top
- **Chart**: Visual representation of your weight over time with interactive hover details
- **History**: Chronological list of all entries with weight changes between entries

### Editing Entries
- Click the "Edit" button next to any entry in the history
- The form will populate with the entry's data
- Make your changes and click "Update Entry"

### BMI Tracking
- Enter your height in centimeters in the BMI Calculator section
- Your BMI will automatically calculate based on your most recent weight
- The app will show your BMI category (Underweight, Normal, Overweight, Obese)
